## Условие задачи  
Составьте программу, определяющую название ноты по ее номеру: 1 –До, 2 – Ре и т.д. При вводе числа вне диапазона от 1 до 7 программа должна выдать сообщение об ошибке.


## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**  
2. Объявить переменные:  
   - `int n;` - номер ноты
3. Вывести приглашение к вводу: ` puts("Введите номер ноты:");`  
4. Ввести номер ноты: `scanf("%d", &n);`
5. Обработка значений: ` switch (n)`
`case 1:
puts("Это нота До");`  
`break;`  
`case 2:
puts("Это нота Ре");`  
`break;`  
`case 3:
puts("Это нота Ми");`  
`break;`  
`case 4:
puts("Это нота Фа");`  
`break;`  
`case 5:
puts("Это нота Соль");`  
`break;`  
`case 6:
puts("Это нота Ля");`  
`break;`  
`case 7:
puts("Это нота Си");`  
`break;`  
6.Обработка неверного значения:  
`default:`  
`puts("Ошибка!!!!( номер должен быть от 1 до 7)");`  
`break;`

## 2. Реализация программы

```c
﻿#include <stdio.h>
#include <locale.h>
//Контрольные примеры:
//n=1 ---> Это нота До
//n=-5 ---> Ошибка!!!!( номер должен быть от 1 до 7)
//n = 4 ---> Это нота Фа
int main()
{
    setlocale(LC_CTYPE, "UTF-8");
    int n;
    puts("Введите номер ноты:");
    scanf("%d", &n);

    switch (n) 
    {
    case 1:
        puts("Это нота До");
        break;
    case 2:
        puts("Это нота Ре");
        break;
    case 3:
        puts("Это нота Ми");
        break;
    case 4:
        puts("Это нота Фа");
        break;
    case 5:
        puts("Это нота Соль");
        break;
    case 6:
        puts("Это нота Ля");
        break;
    case 7:
        puts("Это нота Си");
        break;
    default:
        puts("Ошибка!!!!( номер должен быть от 1 до 7)");
        break;
    }

  ;
}
```
